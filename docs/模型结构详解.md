## 模型概述

STGCN（Spatio-Temporal Graph Convolutional Network，时空图卷积网络）是一个用于能源系统预测的深度学习模型。该模型能够同时处理：
- **时间依赖关系**：通过时间卷积捕获历史数据的时间模式
- **空间依赖关系**：通过图卷积捕获节点之间的空间关联
- **多类型节点**：同时处理蒸汽节点（24个）和压缩空气节点（7个），共31个节点

### 输入输出
- **输入**：
  - 蒸汽节点特征：`[batch_size, 2, 12, 24]` （2个特征：流量G和压力P，12个时间步，24个节点）
  - 压缩空气节点特征：`[batch_size, 2, 12, 7]` （2个特征，12个时间步，7个节点）
  - 边信息：边索引、边权重等
- **输出**：
  - 预测结果：`[batch_size, 2, 1, 31]` （2个特征：流量G和压力P，1个时间步，31个节点）

---

## 整体架构

模型采用**编码-处理-解码**的架构：

```
输入层 → 节点嵌入层 → 时空卷积块1 → 时空卷积块2 → 输出层 → 预测结果
```

### 详细结构图

## 各层详细说明

### 1. 节点嵌入层 (NodeEmbedding)

**作用**：将原始节点特征（流量G和压力P，维度为2）转换为更高维的嵌入表示（维度为12），增强模型的表达能力。

**实现方式**：使用一维傅里叶神经算子（FNO1d）对每个节点的时间序列进行特征提取。

#### 矩阵尺寸变化

```
输入: [batch_size, 2, 12, n_nodes]
      ↓ reshape & permute
      [batch_size * n_nodes, 12, 2]
      ↓ FNO1d处理
      [batch_size * n_nodes, 12, 12]
      ↓ reshape & permute
输出: [batch_size, 12, 12, n_nodes]
```

**具体示例**：
- 蒸汽节点：`[B, 2, 12, 24]` → `[B, 12, 12, 24]`
- 压缩空气节点：`[B, 2, 12, 7]` → `[B, 12, 12, 7]`
- 拼接后：`[B, 12, 12, 31]`

#### FNO1d内部结构

FNO1d（一维傅里叶神经算子）通过频域卷积捕获时间序列的长期依赖关系：

```
输入: [batch, time_steps, feature_dim]
      ↓ fc0 (Linear: 2 → 128)
      [batch, time_steps, 128]
      ↓ 4层频域卷积 + 空间域卷积（残差连接）
      [batch, time_steps, 128]
      ↓ fc1 (Linear: 128 → 128)
      [batch, time_steps, 128]
      ↓ fc2 (Linear: 128 → 12)
输出: [batch, time_steps, 12]
```

**频域卷积原理**：
1. 对输入进行FFT（快速傅里叶变换）转换到频域
2. 在频域进行复数乘法（只保留前`modes`个频率分量，默认16个）
3. 进行IFFT（逆快速傅里叶变换）转换回时域
4. 与空间域卷积结果相加（残差连接）

**优势**：频域操作可以高效地捕获长期时间依赖，计算复杂度为O(N log N)，比传统RNN的O(N²)更高效。

---

### 2. 边嵌入层 (edge_embed)

**作用**：将边的物理属性（如管道长度和直径）编码为边权重，用于图卷积操作。

#### 矩阵尺寸变化

```
输入: weight1 [num_edges], weight2 [num_edges]
      ↓ 构建特征
      [num_edges, 2]  (特征: [weight2/weight1*ratio, weight2²])
      ↓ fc1 (Linear: 2 → 8)
      [num_edges, 8]
      ↓ fc2 (Linear: 8 → 1)
      [num_edges, 1]
输出: [num_edges, 1]
```

**具体示例**：
- 蒸汽边：23条边 → `[23, 1]`
- 压缩空气边：6条边 → `[6, 1]`
- 虚拟边：1条边 → `[1, 1]`
- 拼接后：`[30, 1]`

#### 边特征与edge_index的对应关系

**关键点**：`edge_weight[i]` 必须对应 `edge_index[:, i]` 这条边的权重！

在代码中，边特征的拼接顺序为：
1. **前23条边**：蒸汽边（对应 `edge_index[:, 0:23]`）
2. **接下来6条边**：压缩空气边（对应 `edge_index[:, 23:29]`）
3. **最后1条边**：虚拟边（对应 `edge_index[:, 29]`）

在 `GraphConvLayer` 中，PyTorch Geometric 的 `GCNConv` 会根据：
- `edge_index`：知道哪两个节点相连
- `edge_weight`：知道每条边的权重（通过索引位置对应）

**详细说明请参考**：`docs/模型实现细节分析.md` 中的"边特征的使用机制"部分。

### 3. 时空卷积块 (STConvBlock)

**作用**：同时捕获时间维度和空间维度的依赖关系。采用**T-G-T-N-D**结构：
- **T**：时间卷积层（Temporal Convolution）
- **G**：图卷积层（Graph Convolution）
- **T**：时间卷积层
- **N**：层归一化（Layer Normalization）
- **D**：Dropout

#### 矩阵尺寸变化（以第一个STConvBlock为例）

```
输入: [batch_size, 12, 12, 31]
      ↓ 时间卷积1 (Kt=3, 12→64)
      [batch_size, 64, 10, 31]  (时间步: 12-3+1=10)
      ↓ 图卷积 (64→64)
      [batch_size, 64, 10, 31]  (时间步不变)
      ↓ 时间卷积2 (Kt=3, 64→64)
      [batch_size, 64, 8, 31]   (时间步: 10-3+1=8)
      ↓ 层归一化 + Dropout
输出: [batch_size, 64, 8, 31]
```

**第二个STConvBlock**：
```
输入: [batch_size, 64, 8, 31]
      ↓ 时间卷积1 (Kt=3, 64→64)
      [batch_size, 64, 6, 31]   (时间步: 8-3+1=6)
      ↓ 图卷积 (64→64)
      [batch_size, 64, 6, 31]
      ↓ 时间卷积2 (Kt=3, 64→64)
      [batch_size, 64, 4, 31]   (时间步: 6-3+1=4)
      ↓ 层归一化 + Dropout
输出: [batch_size, 64, 4, 31]
```

#### 3.1 时间卷积层 (TemporalConvLayer)

**作用**：在时间维度上进行因果卷积，捕获时间依赖关系。支持多种激活函数：
- **GLU**（Gated Linear Unit）：`(x_p + x_in) * sigmoid(x_q)`
- **GTU**（Gated Tanh Unit）：`tanh(x_p + x_in) * sigmoid(x_q)`
- **ReLU**：`ReLU(x + x_in)`
- **SiLU**：`SiLU(x + x_in)`

**因果性保证**：使用左填充（left padding），确保输出只依赖于当前时刻及之前时刻的输入，不会"偷看"未来数据。

#### 矩阵尺寸变化

```
输入: [batch_size, c_in, time_steps, n_vertex]
      ↓ 对齐层 (Align: 调整通道数)
      [batch_size, c_out, time_steps, n_vertex]
      ↓ 因果卷积 (kernel_size=Kt, 无填充)
      [batch_size, c_out, time_steps-Kt+1, n_vertex]
      ↓ 残差连接 + 激活函数
输出: [batch_size, c_out, time_steps-Kt+1, n_vertex]
```

**具体示例**（第一个时间卷积，Kt=3）：
- 输入：`[B, 12, 12, 31]`
- 对齐：`[B, 64, 12, 31]`（如果c_in < c_out，使用零填充）
- 卷积：`[B, 128, 10, 31]`（GLU/GTU需要2倍通道）
- 分割：特征部分`[B, 64, 10, 31]`，门控部分`[B, 64, 10, 31]`
- 残差：`[B, 64, 10, 31]`（只对后10个时间步进行残差连接）
- 输出：`[B, 64, 10, 31]`

#### 3.2 图卷积层 (GraphConvLayer)

**作用**：在空间维度（节点维度）上进行信息传播，捕获节点之间的空间依赖关系。

**实现方式**：使用两层GCN（Graph Convolutional Network）：
1. 第一层：`in_channels → 64`
2. 第二层：`64 → out_channels`

#### 矩阵尺寸变化

```
输入: [batch_size, c_in, time_steps, n_vertex]
      ↓ 对每个时间步分别处理
      for t in range(time_steps):
          x_t: [batch_size, c_in, n_vertex]
          ↓ transpose
          [batch_size, n_vertex, c_in]
          ↓ GCN1 (c_in → 64)
          [batch_size, n_vertex, 64]
          ↓ GCN2 (64 → c_out)
          [batch_size, n_vertex, c_out]
          ↓ transpose
          [batch_size, c_out, n_vertex]
      ↓ stack
输出: [batch_size, c_out, time_steps, n_vertex]
```

**注意**：图卷积在时间维度上独立处理，时间步数保持不变。

**GCN原理**：
- 对每个节点，聚合其邻居节点的特征
- 使用边权重控制信息传播的强度
- 公式：`H^(l+1) = σ(D^(-1/2) A D^(-1/2) H^(l) W^(l))`
  - `A`：邻接矩阵（带权重）
  - `D`：度矩阵
  - `H^(l)`：第l层的节点特征
  - `W^(l)`：可学习的权重矩阵

---

### 4. 输出层 (OutputBlock)

**作用**：将时空特征转换为最终的预测结果（流量G和压力P）。

**结构**：**T-N-F-F**
- **T**：时间卷积层（将剩余时间步压缩为1）
- **N**：层归一化
- **F**：全连接层1（128 → 128）
- **F**：全连接层2（128 → 2）

#### 矩阵尺寸变化

**情况1：Ko > 1（使用OutputBlock）**

```
输入: [batch_size, 64, 4, 31]
      ↓ 时间卷积 (Kt=Ko, 64→128)
      [batch_size, 128, 1, 31]  (时间步: 4-Ko+1=1)
      ↓ 层归一化 (permute: [B,1,31,128])
      [batch_size, 1, 31, 128]
      ↓ fc1 (Linear: 128 → 128)
      [batch_size, 1, 31, 128]
      ↓ fc2 (Linear: 128 → 2)
      [batch_size, 1, 31, 2]
      ↓ permute
输出: [batch_size, 2, 1, 31]
```

**情况2：Ko = 0（使用全连接层）**

如果时间维度被完全压缩（Ko=0），则使用全连接层。**注意**：这种情况在实际使用中很少出现，因为需要满足 `n_his = (Kt-1) * 2 * stblock_num`。

```
输入: [batch_size, 64, 0, 31]  (时间步已为0)
      ↓ squeeze & permute
      [batch_size, 31, 64]  (需要重塑张量，移除时间维度)
      ↓ fc1 (Linear: 64 → 128)
      [batch_size, 31, 128]
      ↓ fc2 (Linear: 128 → 2)
      [batch_size, 31, 2]
      ↓ permute & unsqueeze
输出: [batch_size, 2, 1, 31]
```

**⚠️ 注意**：当前代码中 `Ko=0` 的处理逻辑可能存在问题，详见 `docs/模型实现细节分析.md`。

**Ko的计算**：
```python
Ko = n_his - (stblock_num) * 2 * (Kt - 1)
   = 12 - 2 * 2 * (3 - 1)
   = 12 - 8
   = 4
```

因此，默认配置下使用OutputBlock，时间卷积核大小为4。

假设 `batch_size = B`，使用默认参数：
- `n_his = 12`（历史时间步数）
- `Kt = 3`（时间卷积核大小）
- `n_vertex = 31`（总节点数）
- `n_steam = 24`（蒸汽节点数）

└─────────────────────────────────────────────────────────────┘

### 时间维度变化总结

| 阶段 | 时间步数 | 说明 |
|------|---------|------|
| 输入 | 12 | 历史时间步数 |
| 节点嵌入后 | 12 | 保持不变 |
| STConvBlock1后 | 8 | 减少4步（2个时间卷积，每个减少2步） |
| STConvBlock2后 | 4 | 再减少4步 |
| 输出层后 | 1 | 最终预测时间步 |

**计算公式**：
- 每个时间卷积减少：`Kt - 1 = 3 - 1 = 2` 步
- 每个STConvBlock有2个时间卷积，共减少：`2 × 2 = 4` 步
- 2个STConvBlock共减少：`2 × 4 = 8` 步
- 剩余时间步：`12 - 8 = 4` 步
- 输出层时间卷积核：`Ko = 4`，将4步压缩为1步

### 通道维度变化总结

| 阶段 | 通道数 | 说明 |
|------|--------|------|
| 输入 | 2 | 流量G和压力P |
| 节点嵌入后 | 12 | FNO1d输出维度 |
| STConvBlock1 | 64 | 中间层维度 |
| STConvBlock2 | 64 | 保持不变 |
| 输出层 | 128 → 2 | 先扩展到128，再压缩到2 |

## 关键设计思想

### 1. 时空分离设计

模型采用**时空分离**的设计理念：
- **时间维度**：通过时间卷积在时间轴上滑动，捕获时间依赖
- **空间维度**：通过图卷积在节点间传播信息，捕获空间依赖
- **交替处理**：T-G-T结构（时间-图-时间），先处理时间，再处理空间，再处理时间

这种设计的优势：
- 计算效率高：时间卷积和图卷积可以分别优化
- 易于理解：时间依赖和空间依赖分离，便于调试和分析
- 灵活性强：可以独立调整时间卷积核大小和图结构

### 2. 因果性保证

所有时间卷积都使用**因果卷积**（Causal Convolution），确保：
- 输出只依赖于当前时刻及之前时刻的输入
- 不会"偷看"未来数据
- 适合时间序列预测任务

### 3. 残差连接

在时间卷积层中使用残差连接：
- **GLU/GTU**：`(x_p + x_in) * sigmoid(x_q)` 或 `tanh(x_p + x_in) * sigmoid(x_q)`
- **ReLU/SiLU**：`ReLU(x + x_in)` 或 `SiLU(x + x_in)`

残差连接的优势：
- 缓解梯度消失问题
- 允许网络学习恒等映射
- 提高训练稳定性

### 4. 门控机制

使用GLU（Gated Linear Unit）或GTU（Gated Tanh Unit）作为激活函数：
- **门控部分**：控制信息流的强度
- **特征部分**：提取时间特征
- **优势**：可以动态控制信息流，提高模型表达能力

### 5. 频域特征提取

使用FNO（傅里叶神经算子）进行节点嵌入：
- **频域卷积**：在频域进行卷积，高效捕获长期依赖
- **计算复杂度**：O(N log N)，比RNN的O(N²)更高效
- **适用场景**：适合处理周期性或长期依赖的时间序列

### 6. 多类型节点处理

模型同时处理两种类型的节点：
- **蒸汽节点**：24个节点，特征维度2
- **压缩空气节点**：7个节点，特征维度2
- **虚拟边**：连接不同类型的节点，允许跨类型信息传播

### 7. 边权重学习

边权重不是固定的，而是通过神经网络学习：
- **输入**：边的物理属性（长度、直径等）
- **输出**：可学习的边权重
- **优势**：可以根据任务自动调整边的重要性

## 总结

STGCN模型通过精心设计的时空卷积结构，能够有效地：
1. **捕获时间依赖**：通过多层时间卷积提取时间模式
2. **捕获空间依赖**：通过图卷积传播节点间信息
3. **处理多类型节点**：统一处理不同类型的节点
4. **保证因果性**：确保预测不会使用未来信息
5. **高效计算**：使用频域卷积和时空分离设计提高效率

模型的核心思想是**时空分离**和**交替处理**，通过时间卷积和图卷积的交替使用，逐步提取和融合时空特征，最终生成准确的预测结果。
