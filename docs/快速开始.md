# 快速开始指南

## 第一步：环境准备

### 1.1 安装Python依赖

```bash
# 使用uv pip（推荐）
uv pip install torch torch-geometric numpy pandas scikit-learn openpyxl tqdm

# 或使用pip
pip install torch torch-geometric numpy pandas scikit-learn openpyxl tqdm
```

### 1.2 验证安装

```python
import torch
import torch_geometric
print(f"PyTorch版本: {torch.__version__}")
print(f"CUDA可用: {torch.cuda.is_available()}")
```

## 第二步：准备数据

### 2.1 数据格式要求

Excel文件应包含以下格式：
- **行**：每个时间步
- **列**：每个节点
- **文件**：
  - `steam_G.xlsx`: 蒸汽流量数据
  - `steam_P.xlsx`: 蒸汽压力数据
  - `preair_G.xlsx`: 电力流量数据
  - `preair_P.xlsx`: 电力压力数据

### 2.2 首次数据预处理

编辑 `main.py`，取消注释以下代码：

```python
GATG = 'data/steam_G.xlsx'
GATP = "data/steam_P.xlsx"
GATE1 = 'data/preair_G.xlsx'
GATE2 = "data/preair_P.xlsx"
data_preparate(args, GATG, GATP, GATE1, GATE2, device)
```

运行一次后，会生成预处理数据文件，之后可以注释掉这段代码。

## 第三步：运行训练

### 3.1 基础训练

```bash
python main.py
```

### 3.2 自定义参数训练

```bash
python main.py \
    --epochs 50 \
    --batch_size 64 \
    --lr 0.0005 \
    --patience 20 \
    --n_his 12 \
    --n_pred 3
```

### 3.3 使用PDE损失训练

```bash
python main.py --need_grad True
```

## 第五步：常见问题排查

### 5.1 数据文件不存在

**错误**：`FileNotFoundError: data/data.pickle`

**解决**：运行数据预处理步骤（第二步）

### 5.2 CUDA内存不足

**错误**：`RuntimeError: CUDA out of memory`

**解决**：
- 减小 `batch_size`（如改为32或64）
- 减小 `n_his`（历史时间步数）
- 使用CPU：`--enable_cuda False`

### 5.3 图结构不匹配

**错误**：维度不匹配相关错误

**解决**：
- 检查节点数量参数（`--n_vertex`, `--n_steam`, `--n_air`）
- 检查数据文件中的节点数是否与参数一致

### 5.4 依赖包缺失

**错误**：`ModuleNotFoundError`

**解决**：
```bash
# 安装缺失的包
uv pip install <包名>
```

## 第六步：XGBoost超参数优化（可选）

### 6.1 安装Optuna

```bash

```

### 6.2 运行超参数优化

```bash
# 基本用法（50次试验）
python xgboost_method_v3.py --optimize_params

# 自定义试验次数和超时时间
python xgboost_method_v3.py --optimize_params --n_trials 100 --optimization_timeout 7200
```

### 6.3 查看优化结果

优化完成后，会在报告目录中生成：
- 优化历史可视化图表（HTML格式）
- 最佳超参数配置
- 优化后的模型性能报告

详细说明请参考：`docs/XGBoost超参数优化说明.md`

## 提示

- **首次运行**：建议先用小数据集测试，确认环境配置正确
- **参数调优**：从默认参数开始，逐步调整
- **保存模型**：训练过程中会定期保存模型检查点
- **日志记录**：可以启用TensorBoard记录训练过程（需要取消注释相关代码）
