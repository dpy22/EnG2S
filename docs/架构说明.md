# 代码架构说明文档

## 1. 整体架构

本项目采用模块化设计，主要分为以下几个部分：

```
┌─────────────────────────────────────────────────────────┐
│                      main.py                             │
│  (参数解析、数据加载、训练流程控制)                        │
└──────────────┬──────────────────────────────────────────┘
               │
    ┌──────────┴──────────┐
    │                     │
┌───▼────────┐    ┌───────▼────────┐
│  model/   │    │    script/      │
│           │    │                 │
│ my_model  │    │  get_data       │
│ my_layers │    │  utility        │
│           │    │  earlystopping  │
└───────────┘    └─────────────────┘
```

## 2. 数据流

### 2.1 数据加载流程

```
Excel文件 (.xlsx)
    ↓
get_train_data() / get_load_data()
    ↓
DataFrame / NumPy数组
    ↓
data_transform() (滑动窗口)
    ↓
PyTorch张量
    ↓
data_split() (转换为图数据)
    ↓
Data对象列表
    ↓
DataLoader (批处理)
    ↓
训练/验证/测试
```

### 2.2 模型前向传播流程

```
输入数据
    ↓
┌─────────────────────────────────────┐
│  节点嵌入层 (NodeEmbedding)         │
│  - 蒸汽节点: FNO嵌入                │
│  - 电力节点: FNO嵌入                │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│  边嵌入层 (edge_embed)               │
│  - 蒸汽边: 物理属性 → 边权重         │
│  - 电力边: 物理属性 → 边权重         │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│  特征拼接                            │
│  [蒸汽节点, 电力节点]                │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│  时空卷积块1 (STConvBlock)          │
│  - 时间卷积 → 图卷积 → 时间卷积      │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│  时空卷积块2 (STConvBlock)          │
│  - 时间卷积 → 图卷积 → 时间卷积      │
└──────────────┬──────────────────────┘
               ↓
┌─────────────────────────────────────┐
│  输出层 (OutputBlock / FC)          │
│  - 时间卷积 → 全连接 → 全连接        │
└──────────────┬──────────────────────┘
               ↓
           预测输出
      [流量G, 压力P]
```

## 3. 核心模块详解

### 3.1 模型层 (model/)

#### 3.1.1 NodeEmbedding
- **功能**：对节点特征进行嵌入
- **实现**：使用FNO1d对每个节点的特征序列进行处理
- **输入**：`[batch_size, feature_dim, time_steps, num_nodes]`
- **输出**：`[batch_size, embed_dim, time_steps, num_nodes]`

#### 3.1.2 FNO1d
- **功能**：一维傅里叶神经算子
- **原理**：在频域进行卷积，捕获长期时间依赖
- **结构**：
  - 输入投影层（Linear）
  - 4个谱卷积层（SpectralConv1d）+ 空间卷积层（残差连接）
  - 输出投影层（Linear）

#### 3.1.3 TemporalConvLayer
- **功能**：时间维度上的因果卷积
- **特点**：支持GLU/GTU门控激活函数
- **输入**：`[batch_size, c_in, time_steps, n_vertex]`
- **输出**：`[batch_size, c_out, time_steps-Kt+1, n_vertex]`

#### 3.1.4 GraphConvLayer
- **功能**：空间维度上的图卷积
- **实现**：对每个时间步分别进行GCN操作
- **输入**：`[batch_size, c_in, time_steps, n_vertex]`
- **输出**：`[batch_size, c_out, time_steps, n_vertex]`

#### 3.1.5 STConvBlock
- **功能**：时空卷积块，同时处理时间和空间维度
- **结构**：T-G-T-N-D
  - T: 时间卷积
  - G: 图卷积
  - T: 时间卷积
  - N: 层归一化
  - D: Dropout

### 3.2 数据模块 (script/get_data.py)

#### 3.2.1 get_train_data()
- **功能**：从Excel文件加载原始数据
- **返回**：DataFrame和物理参数张量

#### 3.2.2 data_transform()
- **功能**：将时间序列转换为滑动窗口格式
- **方法**：使用滑动窗口生成输入-输出对

#### 3.2.3 data_split()
- **功能**：将数据转换为PyTorch Geometric的Data对象
- **特点**：每个样本包含完整的图结构信息

### 3.3 工具模块 (script/utility.py)

#### 3.3.1 evaluate_model()
- **功能**：计算模型在数据集上的MSE损失

#### 3.3.2 evaluate_metric()
- **功能**：计算详细的评估指标（MAE, RMSE, WMAPE）
- **特点**：分别计算蒸汽和电力的流量和压力指标

#### 3.3.3 custom_collate()
- **功能**：自定义批处理函数
- **特点**：处理图数据的批处理，共享图结构

#### 3.3.4 calculate_pde_loss()
- **功能**：计算PDE损失
- **原理**：基于物理方程计算残差

## 4. 训练流程

```
1. 参数解析 (get_parameters)
   ↓
2. 环境设置 (set_env)
   ↓
3. 数据加载 (load_data)
   ↓
4. 模型初始化 (prepare_model)
   ↓
5. 训练循环 (train)

   ↓
6. 测试评估 (test)
   └─ 计算详细指标
```

## 5. 关键设计决策

### 5.1 为什么使用FNO？
- **长期依赖**：FNO在频域操作，能够捕获长期时间依赖关系
- **计算效率**：频域卷积比时域卷积更高效

### 5.2 为什么使用因果卷积？
- **时间因果性**：确保预测只使用历史信息，不会"偷看"未来
- **实时预测**：适合在线预测场景

### 5.3 为什么分离蒸汽和电力节点？
- **不同类型**：蒸汽和电力系统有不同的物理特性
- **独立嵌入**：可以学习不同类型的特征表示
- **灵活组合**：通过图结构连接不同类型的节点

### 5.4 为什么使用边嵌入？
- **物理约束**：边的物理属性（长度、直径）影响信息传播
- **可学习权重**：通过神经网络学习最优的边权重表示

## 6. 扩展建议

### 6.1 添加新的节点类型
1. 在 `NodeEmbedding` 中添加新的嵌入层
2. 在 `forward()` 中拼接新节点特征
3. 更新图结构（edge_index）

### 6.2 修改图结构
1. 在 `get_data.py` 中修改 `edge_index`
2. 更新节点数量参数（n_vertex, n_steam, n_air）
3. 调整边属性（S1, S2, E1, E2）

### 6.3 添加新的损失函数
1. 在 `utility.py` 中实现新损失函数
2. 在 `train()` 函数中集成新损失
3. 调整损失权重

### 6.4 优化模型结构
1. 调整STConv块数量（stblock_num）
2. 修改各层通道数（blocks配置）
3. 尝试不同的激活函数（act_func）

## 7. 性能优化建议

1. **数据预处理**：使用pickle保存预处理后的数据，避免重复处理
2. **批处理大小**：根据GPU内存调整batch_size
3. **混合精度训练**：使用torch.cuda.amp加速训练
4. **数据并行**：多GPU训练时使用DataParallel或DistributedDataParallel

## 8. 调试技巧

1. **检查数据形状**：在每个关键步骤打印张量形状
2. **可视化图结构**：使用networkx可视化图结构
3. **监控损失**：使用TensorBoard记录训练过程
4. **梯度检查**：检查梯度是否正常（无NaN、无爆炸）
