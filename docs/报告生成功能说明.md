# 训练报告生成功能说明

## 功能概述

训练报告生成功能会在每次运行结束后自动生成一份详细的markdown格式报告，包含训练过程的完整记录、模型信息、评估结果和可视化图表。

## 报告内容

生成的报告包含以下内容：

### 1. 运行概览
- 总运行时间
- 训练轮数
- 最终训练损失和验证损失
- 测试损失

### 2. 模型结构
- 模型基本信息（名称、参数量等）
- 模型结构配置（blocks）
- 完整模型结构（PyTorch模型字符串表示）

### 3. 超参数配置
- 训练参数（epochs、batch_size、lr等）
- 模型结构参数（n_vertex、n_his、n_pred等）
- 完整参数列表（JSON格式，可展开查看）

### 4. 训练过程
- 每个epoch的详细记录（训练损失、验证损失、学习率、GPU内存使用）
- 损失曲线图（普通尺度和对数尺度）
- 学习率变化曲线
- GPU内存使用曲线

### 5. 验证过程
- 最佳验证损失及对应的epoch
- 最终验证损失

### 6. 测试过程
- 测试MSE损失
- 详细评估指标（MAE、RMSE、WMAPE）
  - 蒸汽系统：流量G和压力P的指标
  - 空气系统：流量G和压力P的指标

### 7. 保存的模型权重
- 所有保存的模型文件路径
- 每个模型文件的大小

### 8. 模型最终结果总结
- 训练效果总结（损失降低百分比）
- 测试性能总结

### 9. 可视化图片
- 所有生成的可视化图表保存在 `images/` 子目录下

## 报告存储位置

报告存储在 `reports/` 目录下，每次运行会创建一个带时间戳的文件夹：

```
reports/
└── run_YYYYMMDD_HHMMSS/
    ├── report.md          # 主报告文件
    └── images/            # 可视化图片目录
        ├── loss_curves.png
        ├── learning_rate.png
        └── gpu_memory.png
```

## 使用方法

报告生成功能已自动集成到主程序中，无需额外配置。每次运行 `main.py` 时，程序会自动：

1. 创建报告生成器实例
2. 在训练过程中记录每个epoch的信息
3. 在测试过程中记录评估结果
4. 在程序结束时自动生成并保存报告

## 依赖要求

报告生成功能需要以下额外的Python包：

```bash
uv pip install matplotlib
# 或
pip install matplotlib
```

## 注意事项

1. **matplotlib后端**：报告生成器使用非交互式后端（Agg），适用于无GUI环境（如服务器）
2. **报告大小**：如果模型结构非常复杂，报告可能会很大。模型结构部分如果超过5000字符会被截断
3. **图片格式**：所有可视化图表以PNG格式保存，分辨率为300 DPI
4. **时间戳**：每次运行都会创建新的报告目录，不会覆盖之前的报告

## 示例

运行训练后，会在控制台看到类似输出：

```
报告将保存至: reports/run_20241201_143022
...
训练报告已生成: reports/run_20241201_143022/report.md
```

打开 `report.md` 文件即可查看完整的训练报告。
